Árvores de Habilidade Elementais

Arquitetura de sistema — Ninjutsu de Fogo, Terra, Água, Vento, Raio e o kekkei genkai de Cristal

Documento de design. Define, para cada elemento: identidade de combate, árvore de talentos ramificada (jutsus + passivas), estatísticas propostas de cada técnica (rank, forma, alcance, dano, custo, efeitos), interações com o cenário, combos entre elementos e ganchos para o futuro sistema de /fugir.

Os números seguem as convenções já vivas em src/config/balance.ts (dano = base + atributo × escala, escala de Ninjutsu = 2.0) e usam os efeitos reais de src/config/enums.ts. Onde algo novo é proposto, está marcado NOVO e detalhado no apêndice técnico.

Como ler os ranks. O rank é o poder canônico da técnica (base no anime/mangá). O tier é a profundidade dela na árvore. Cada elemento tem pelo menos um jutsu rank A e um rank S.
D aquecimento   C genin+   B chunin   A jounin / assinatura   S kage / custo altíssimo de chakra
Rank S custa de 70 a 80% do chakra. Algumas técnicas ainda possuem regra própria; Kirin, por exemplo, só pode ser usado uma vez por combate.
Kekkei genkai. Além dos cinco elementos básicos existem os elementos de linhagem sanguínea. Para a engine um kekkei genkai é um elemento como qualquer outro — tem árvore, passivas e requisitos iguais. Três coisas o separam:
  • Não é sorteado. Afinidade básica cai por acaso; kekkei genkai só entra pelo /admin.
  • Bate mais forte. As passivas de dano fecham em ~2,30× em vez dos ~2,015× dos básicos (+14%). O teste de balanceamento usa uma faixa separada (2,2–2,5×) para eles.
  • Tem efeitos próprios. Estados de combate que nenhum elemento básico consegue produzir.
Implementado hoje: Cristal (Shōton).

Legenda do sistema

Progressão da árvore

Cada elemento tem sua própria árvore. O personagem só acessa uma árvore se tiver recebido aquela afinidade elemental; a afinidade é definida aleatoriamente, não comprada na árvore. Os nós são comprados com Pontos de Ninjutsu (PN), e a moeda é o próprio atributo Ninjutsu: cada ponto investido em Ninjutsu no /atributos vira 1 PN para gastar na árvore (você ganha 4 pontos de atributo por nível). Comprar um nó não reduz o atributo. Ninjutsu funciona como orçamento da árvore; o dano base das técnicas não escala com esse atributo:
disponível = Ninjutsu − (soma dos custos dos nós já comprados).

Ou seja: quem despeja tudo em Ninjutsu tem uma árvore farta mas pega leve nos outros atributos; quem espalha, escolhe poucos ramos. A escolha dos ramos é o que dá identidade ao build. O site Pergaminho das Técnicas valida cada compra no servidor (nada é decidido no navegador).

  • Tronco — a coluna central desce do nó-raiz até o jutsu rank S no pé. É a espinha do elemento.
  • Ramificações — brotam do tronco em profundidades diferentes (não todas no topo): cada offshoot é uma especialização curta (1–2 nós) que só aparece conforme você desce a árvore.
  • Nó de Jutsu = caixa sólida com o rank. Nó de Passiva = caixa tracejada, prefixo ◆.
  • Um nó só abre se o nó anterior na mesma linha (tronco ou ramo) foi comprado e os requisitos de nível + Ninjutsu baterem.

🔥 FOGO — KatonFogo

Papel: Incinerador — o maior dano bruto do jogo e a única fonte de dano que cresce sozinho.

Fogo não controla nem se defende bem: ele queima. Cada acerto empilha BURN, e o build inteiro gira em torno de chegar aos stacks de explosão (40 de dano numa tacada) antes de o inimigo se curar ou se molhar. Também é o único elemento que nega área com anéis de fogo e cortinas de cinza, e traz a assinatura anti-fuga do jogo. Fraqueza clara: WET e Água apagam suas stacks.

🪨 TERRA — DotonTerra

Papel: Fortaleza — remodela o campo, prende, aguenta pancada e traz reforços.

Terra tem o menor burst dos cinco, e compensa com presença: ergue muros que bloqueiam linha e movimento, cria SHIELD, prende com ROOT/PULL, e é o único elemento com invocações (clone e golem) e um golpe físico que escala Taijutsu. É o build que decide onde a luta acontece.

💧 ÁGUA — SuitonÁgua

Papel: Controlador — reposiciona, prende, e molha o campo para armar o combo com Raio.

Água é o elemento de setup. Dano honesto, mas o valor está em KNOCKBACK/PULL para tirar o inimigo de posição, ROOT para prender, e sobretudo em espalhar WET e células de água pelo mapa. Com Nuvens de Tempestade, Raio causa +75% de dano a alvos Encharcados; Assassinato Eletromagnético também usa o estado para formar sua corrente. É o parceiro de combo número um do jogo.

🌪️ VENTO — FuutonVento

Papel: Lâmina de precisão — indefensável, perfura defesa, corta (BLEED) e empurra.

Vento é a resposta contra quem esquiva e bloqueia: suas técnicas de assinatura são undodgeable e ignoram bloqueio. Corta em vez de espancar (aplica BLEED, que pune o alvo por usar Taijutsu), tem o maior alcance do jogo e usa KNOCKBACK para ditar posição. Glass cannon de precisão: acerta sempre, mas não se defende.

⚡ RAIO — RaitonRaio

Papel: Assassino — velocidade, atordoar, perfurar e o maior burst single-target, com payoff no combo com Água.

Raio é o finalizador. Stun-lock com STUN, perfuração que ignora defesa, e um teto de dano altíssimo em alvo único. Seu segredo é a condução: a passiva Nuvens de Tempestade dá +75% de dano contra alvos WET, enquanto Assassinato Eletromagnético usa esse estado para encadear e Atordoar. A Armadura melhora mobilidade, esquiva e fuga sem torná-la garantida; Kirin é o ápice em área.

3b. Kekkei genkai — como a engine trata

Não há caminho de código separado: um KG é um Element normal em ELEMENTS, com árvore em ELEMENT_TREES e passivas em PASSIVES. O que o distingue:

KEKKEI_GENKAI = ["CRISTAL"]      // subconjunto de ELEMENTS
isKekkeiGenkai(element)          // usado na UI e na faixa de balanceamento

// Afinidade nao e' sorteada em lugar nenhum do codigo: CharacterElement so' e'
// preenchido via /admin. Por isso adicionar um KG a ELEMENTS nao faz ele cair
// no rolo de ninguem.

// Faixa do teste de dano (tests/passives.test.ts):
//   elemento basico -> 1.8 a 2.2x
//   kekkei genkai   -> 2.2 a 2.5x

Campo novo em PassiveDef para o Cristal: extraCrystalStacks (espelho de extraBurnStacks), agregado em PassiveMods e consumido em resolveHit na hora de aplicar CRYSTALLIZED.

Dano não escala mais com atributo. ninjutsuScaling, taijutsuScaling, bukijutsuScaling e iryoNinjutsuScaling estão em 0. O dano de um jutsu é baseDamage × (passivas de dano do elemento). O crescimento vem da árvore, não de acumular atributo — dois ninjas do mesmo nível batem diferente conforme a build. O produto das passivas de dano de cada elemento deve ficar perto de 2.0× (há teste que trava isso). Ninjutsu segue valendo muito: é o orçamento da árvore. Taijutsu dá HP, movimento, esquiva e fuga.

4. SHIELD / barreira

Campo shield: number no CombatParticipant. Em resolveHit(), o dano desconta do shield antes do HP. Terra é quem gera. Raio (Ponta Perfurante) ignora.

5. Invocações (sistema maior)

Clones e golem entram como CombatParticipant aliados, com HP, célula e IA simples (reusa npc-combat.ts). Dá para adiar: nada mais no design depende disso. Marcar os quatro nós de invocação como fase 2.

6. Árvore & Pontos de Ninjutsu JÁ IMPLEMENTADO

Moeda = valor do atributo Ninjutsu (não um saldo separado). Investir em Ninjutsu no /atributos aumenta o orçamento; comprar um nó não desconta o atributo, só o orçamento: disponível = ninjutsu − Σ custos dos nós comprados. Ganho de 4 pontos de atributo por nível (balance.attributePointsPerLevel = 4). Nós comprados persistem em CharacterSkillNode; a compra é validada no servidor em services/characters/skill-tree.ts (o site nunca decide nada).

// Modelo real em src/data/element-trees/index.ts
interface SkillTreeNode {
  id: string
  element: Element
  branch: string              // "tronco" | "brasa" | "cerco" | ...
  kind: "JUTSU" | "PASSIVE"
  cost: number                // PN
  requiresLevel: number
  requiresNinjutsu: number
  requiresNodes?: string[]    // no anterior (tronco ou offshoot) -> desenha a espinha
  grantsAbilityId?: string    // se JUTSU
  passive?: { ... }           // se PASSIVE (ex.: { katonDmgMult: 1.15 })
}

A topologia tronco+ramificações é só o grafo de requiresNodes: o tronco é uma cadeia linear (raiz → … → S) e cada offshoot aponta para o nó do tronco de onde brota. Persistir os nós comprados por personagem (tabela CharacterElementNode). O painel pode reusar a UI de /atributos (StringSelect de ramos + botões por nó).

7. Números — dano e freio do rank S

O dano não recebe escala direta de Ninjutsu. Ele parte do baseDamage e é multiplicado pelas passivas da árvore. As rotas de dano completo dos cinco básicos ficam próximas de 2,0×; Raio chega a 2,01× contra alvo Encharcado ao combinar Sinapse Acelerada (1,15×) com Nuvens de Tempestade (1,75×). Kekkei genkai fecha mais alto: Cristal chega a 2,295× (Estrutura Cristalina 1,35× × Faceta Perfeita 1,70×), +14% sobre os básicos — e sem depender de condicional, ao contrário de Água e Raio.

O primeiro freio de um rank S é econômico: cada disparo custa 70–80% do chakra (resourceMax = 100). Técnicas específicas podem ter uma trava adicional. Kirin custa 70, exige chamas ativas ou Nuvens de Tempestade e só pode ser usado uma vez por combate. Os valores de balanceamento ficam em balance.ts e nas definições das habilidades.

Fontes de verdade: efeitos e números globais em src/config; habilidades em src/data/jutsus; topologia e passivas em src/data/element-trees; resolução das interações em src/services/combat.
