# Fontes dos ícones Uchiha

Os três ícones foram convertidos de SVG para PNG 200×200, preservando a
transparência. Nenhuma alteração artística foi feita além da conversão e do
redimensionamento.

- `sharingan-1-tomoe.png`: [Sharingan simple.svg](https://commons.wikimedia.org/wiki/File:Sharingan_simple.svg)
- `sharingan-2-tomoe.png`: [Sharingan double.svg](https://commons.wikimedia.org/wiki/File:Sharingan_double.svg)
- `sharingan-3-tomoe.png`: [Sharingan triple.svg](https://commons.wikimedia.org/wiki/File:Sharingan_triple.svg)
- `mangekyo-sharingan.png`: [Mangekyou Sharingan Madara.svg](https://commons.wikimedia.org/wiki/File:Mangekyou_Sharingan_Madara.svg)

As imagens `controle-ocular.png` e `economia-visual.png` são composições de
interface derivadas dos ícones de Sharingan acima, com marcadores de mira e
chakra adicionados para representar as passivas.
